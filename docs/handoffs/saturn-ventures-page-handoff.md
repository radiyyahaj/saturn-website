# Saturn Ventures — Website Page Handoff

**For:** Claude / Claude Code  
**Page:** Saturn Ventures  
**Tone:** Corporate, confident, established. Short sentences. Affirmative only.  
**Primary accent:** Purple, consistent with the rest of the Saturn site.

---

## Copy rules (non-negotiable)

- Write only what Saturn does. Never what it does not do.
- Never use: "we don't", "we do not", "we aren't", "unlike", "instead of".
- Never sound early, formative, or unfinished.
- No contact section on this page. Site-wide Get in Touch handles that.
- No eligibility list, no legal disclaimer, no CTA block.
- Keep the page lean: Hero → How we invest → Focus.
